# Security

Report a vulnerability privately with "Report a vulnerability" under the
Security tab of the ZeroByte repository it concerns, or by email to
[security@zerobyte.cloud](mailto:security@zerobyte.cloud). Each repository has its own
security policy.

Illegal content or abuse of relay.zerobyte.cloud: [abuse@zerobyte.cloud](mailto:abuse@zerobyte.cloud).
Requests from authorities: [legal@zerobyte.cloud](mailto:legal@zerobyte.cloud).
